Security & Data Privacy Compliance Notice
RENATA PLC (RPPF Production) — Internal Audit & IT Compliance

1. 100% Client-Side Processing: এই অ্যাপ্লিকেশনটি সম্পূর্ণ স্ট্যাটিক প্রোগ্রেসিভ ওয়েব অ্যাপ (PWA) আর্কিটেকচারে নির্মিত। কোনো থার্ড-পার্টি সার্ভার, বাহ্যিক ডাটাবেস বা ট্র্যাকিং স্ক্রিপ্টে কর্মীদের তথ্য পাঠানো হয় না।

2. Salary & Personal Preferences Privacy: পে-স্লিপ ক্যালকুলেটরে ইউজার যে মাসিক বেতন ইনপুট দেন তা শুধুমাত্র ইউজারের নিজস্ব ফোনের লোকাল স্টোরেজে (localStorage) থাকে; কখনোই সার্ভারে প্রেরণ করা হয় না।

3. RPPF Cloud Server Access Control: শুধুমাত্র অনুমোদিত অ্যাডমিন এনক্রিপ্টেড HTTPS সংযোগের মাধ্যমে প্রি-ইনডেক্সড ওভারটাইম সামারি (data/YYYY-MM.json) আপডেট করতে পারেন।

4. Zero External Telemetry: অ্যাপে কোনো বিজ্ঞাপন, অ্যানালিটিক্স বা বাহ্যিক ডেটা মাইনিং SDK যুক্ত নেই।

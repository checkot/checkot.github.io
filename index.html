এই মাসের সার্ভারে থাকা ডাটা:
মাস সিলেক্ট করে "চেক করুন" চাপুন।
নতুন নোটিশ প্রকাশ করুন (`notices.json`)
এখান থেকে নোটিশ পোস্ট করলে অ্যাপের হোমপেজ ও নোটিশ বোর্ডে সাথে সাথে ভেসে উঠবে।
বর্তমান নোটিশ তালিকা:
RPPF Cloud Server কানেকশন ও পাসওয়ার্ড সেটিংস
অ্যাপের ভেতর থেকে সরাসরি RPPF Cloud Server-এ ফাইল আপলোড করতে আপনার Server Access Key একবার নিচে বসিয়ে সেভ করে নিন।
এই Server Access Key শুধুমাত্র আপনার ফোনের ব্রাউজারে (`localStorage`) সংরক্ষিত থাকে।
১ মিনিটে Server Access Key কীভাবে সেটআপ করবেন?
  1. আপনার RPPF Cloud Server অ্যাকাউন্টে লগইন থাকা অবস্থায় Developer Settings → Access Keys (Classic)-এ যান।
  2. Generate New Key বাটনে ক্লিক করুন।
  3. Note-এ Renata App Admin লিখুন, Expiration-এ No expiration দিন এবং নিচে ফুল অ্যাক্সেস অপশনে টিক দিন।
  4. জেনারেট হওয়া Server Access Key কপি করে উপরের বক্সে বসিয়ে সেভ ও কানেকশন টেস্ট চাপুন।

Security & Data Privacy Compliance Notice
RPPF Production — Internal Audit & IT Compliance

1. 100% Client-Side Processing: This application is built as a fully static Progressive Web App (PWA). No employee data is sent to any third-party server, external database or tracking script.

2. Salary & Personal Preferences Privacy: The monthly salary a user enters in the payslip calculator stays only in the local storage of the user device (localStorage) and is never sent to any server.

3. RPPF Cloud Server Access Control: Only an authorized admin can update the pre-indexed overtime summary (data/YYYY-MM.json) over an encrypted HTTPS connection.

4. Zero External Telemetry: The app contains no ads, analytics or external data-mining SDK.
